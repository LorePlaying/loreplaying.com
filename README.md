# L🫆RE PLAYING

> **Role-play on the canonic stories.**

[**Lore Playing**](https://loreplaying.com/) is a creative project built around the **Lore Play Workflow (LPW)** — a framework for transforming established stories, myths, literature, and other canonical works into interactive role-playing experiences.

The project explores what happens when a known story becomes something that can be **played**, rather than simply read or watched.

## About

Lore Playing is the central home for projects created with the Lore Play Workflow.

The idea is simple:

**Start with lore.
Understand the canon.
Build the world.
Play within it.**

Rather than replacing the original story, Lore Playing uses canonical material as a foundation for new interactive experiences.

## Lore Play Workflow

This project relies on **LPW — Lore Play Workflow**.

LPW is a workflow for creating interactive narratives through lore. It can be adapted to different formats, including games, visual novels, role-playing experiences, and other interactive forms.

→ [**Lore Play Workflow**](https://github.com/kamilfatsa/lpw)

## The Website

The [Lore Playing website](https://loreplaying.com/) serves as the central hub for the project.

It currently includes:

* **Library** — a collection of books and literary resources related to the project.
* **🎲 Dice** — a simple D20 tool for role-playing.
* **Contributors** — people who contribute to Lore Playing and its projects.
* **Multilingual support** — available in English and Turkish.

## Projects

Lore Playing is intended to grow as a collection of independent projects built around the same underlying workflow.

Each project can explore a different story, author, mythology, literary work, or fictional universe while remaining connected through the Lore Play approach.
